# Правила Проверки Вопросов Football Quiz (Question Review Rules)

Настоящий регламент определяет обязательные критерии и чеклист для проверки (ревью), составления и локализации вопросов викторины Football Quiz на всех поддерживаемых языках (`ru`, `en`, `hy`, `es`, `de`, `it`).

Каждый вопрос и каждый блок перевода обязан проходить строгую проверку по следующим 5 направлениям:

---

## 1. Проверка по Актуальности (Relevance & Up-to-Dateness)

Футбольная статистика непрерывно обновляется. Вопрос не должен содержать устаревшие данные.

* **Проверка вечных и текущих рекордов:**
  * Убедиться, что исторический рекорд не был побит в недавних сезонах (например, рекорд по хет-трикам в Ла Лиге: у Месси 36, у Роналду 34).
  * Если рекорд был превзойдён, правильный ответ обязан отражать актуального лидера либо вопрос должен содержать ограничительную формулировку (*«Кто первым...»*, *«В XX веке...»*).
* **Проверка количества титулов и трофеев:**
  * Сверять количество побед в турнирах (Кубки, Суперкубки, чемпионаты, еврокубки) с учетом самых последних завершенных сезонов.
  * **Исключение двойного правильного ответа:** Если клуб из вариантов догнал лидера по числу трофеев (как «Атлетик Бильбао», догнавший «Депортиво» по Суперкубкам в 2021 году — по 3 победы), состав вариантов ответа должен быть скорректирован, чтобы верный ответ оставался строго единственным.
* **Временные формы глаголов:**
  * Для прошедших турниров (например, ЧМ-2022, Евро-2024, ЧМ-2026 после его завершения) глаголы должны стоять строго в прошедшем времени (*«приняли / hosted / albergaron»*, а не *«примут / are hosts»*).

---

## 2. Проверка по Футбольной Терминологии (Football Terminology)

Перевод футбольных понятий должен опираться на аутентичную терминологию языка целевой аудитории. Дословные кальки недопустимы.

* **Трофейные связки (Дубли и Треблы):**
  * Победа в Чемпионате, Кубке и Лиге чемпионов (в РФ «золотой хет-трик»):
    * 🇪🇸 Испанский: **el triplete** (категорически запрещено: *Golden Hat Trick*)
    * 🇩🇪 Немецкий: **das Triple** (категорически запрещено: *Golden Hat Trick*)
    * 🇮🇹 Итальянский: **il Triplete** (категорически запрещено: *Golden Hat Trick*)
  * Победа в Чемпионате и Кубке страны («золотой дубль»):
    * 🇪🇸 Испанский: **el doblete** (категорически запрещено: *Golden Double*)
    * 🇩🇪 Немецкий: **das Double** (категорически запрещено: *Golden Double*)
    * 🇮🇹 Итальянский: **il doblete / il double / l'accoppiata campionato-coppa**
* **Футбольные амплуа, действия и номинации:**
  * «Сухой матч» вратаря: *portería a cero / imbatido* (ES), *Zu-null-Spiel* (DE), *porta inviolata / clean sheet* (IT).
  * «Лучший бомбардир»: *máximo goleador / Pichichi* (ES), *Torschützenkönig* (DE), *capocannoniere* (IT).
  * «Лучший ассистент»: *máximo asistente / mejor asistente* (ES), *bester Vorlagengeber* (DE), *miglior assist-man / fornitore di assist* (IT).
  * «Матч сборных»: *partido internacional* (ES), *Länderspiel* (DE), *partita internazionale / incontro della nazionale* (IT).
* **Имена и фамилии футболистов:**
  * Использовать общепринятые спортивные имена, а не паспортные двойные фамилии (например, **Isidro Lángara**, а не *Lángara Galarraga*).
  * Соблюдать корректную транслитерацию и диакритику (Andrés Iniesta, Telmo Zarraonaindía, Raúl, François Gento, आदि).
* **Названия клубов и географических объектов:**
  * Соблюдать национальные нормы написания (в итальянском: *Barcellona*, *Siviglia*, *Maiorca*; в испанском/немецком: *Países Bajos* / *Niederlande* / *Paesi Bassi* вместо устаревшей Голландии).
  * Не путать названия турниров (*Copa del Rey* vs *LaLiga*).

---

## 3. Проверка по Фактам (Factual Accuracy)

Вопрос викторины должен обладать абсолютной исторической и фактической достоверностью.

* **Строгая единственность ответа:**
  * Из 4 предложенных вариантов (A, B, C, D) истинным должен быть ровно один (если только вопрос прямо не подразумевает совместный ответ, например *«Реал Мадрид, Барселона»* или *«Все трое»*).
* **Корректность дистракторов:**
  * Неправильные варианты обязаны быть правдоподобными, но однозначно ошибочными.
  * Дистракторы не должны случайно оказаться правильными при альтернативной трактовке.
* **Сверка цифр и дат:**
  * Год основания турниров (Ла Лига — 1929, Кубок Испании — 1902, Суперкубок — 1982).
  * Счета матчей, число голов, количество матчей без пропущенных мячей (Абель Ресино — 1275 минут).
  * Количество участников турнира (например, 20 клубов в Ла Лиге).

---

## 4. Проверка по Переводам (Translation Integrity)

Техническая и языковая грамотность локализованных структур данных.

* **Синхронизация правильного ответа (`right_answer`):**
  * Поле `right_answer` для каждого языка обязано **в точности** совпадать с текстом одного из вариантов (`answer_A`, `answer_B`, `answer_C` или `answer_D`) для этого языка.
  * Индекс варианта (буква A, B, C или D) для правильного ответа обязан быть **одинаковым во всех языках** (`en`, `ru`, `hy`, `es`, `de`, `it`).
* **Полнота перевода:**
  * Не допускаются пустые строки (`""`).
  * Не допускается попадание непереведённого английского или русского текста в блоки `es`, `de`, `it`, `hy`.
* **Языковая типографика и пунктуация:**
  * Испанский (`es`): обязательное наличие открывающего перевернутого вопросительного знака `¿` в начале вопросов.
  * Немецкий (`de`): правильные немецкие кавычки `„...“` и капитализация всех существительных (*Weltmeisterschaft*, *Saison*, *Verein*).
  * Итальянский (`it`): корректные апострофы и слитные формы (*l’avversario*, *d’Europa*).
  * Армянский (`hy`): правильные вопросительные знаки `՞` над ударной гласной вопросительного слова (например, `Ո՞ր`, `Ո՞վ`, `Քանի՞`).

---

## 5. Проверка по Смыслу (Semantic & Logic Consistency)

Формулировка вопроса должна быть понятной, однозначной и естественной для носителя языка.

* **Эквивалентность исходному смыслу:**
  * Смысл вопроса на `es`, `de`, `it` должен точно передавать суть оригинального вопроса на `ru`/`en`/`hy`, не искажая контекст.
* **Исключение идиоматических нестыковок:**
  * Русские метафоры (например, *«упустил из рук возможность выиграть»*) не должны переводиться буквально. Их следует адаптировать к нормам футбольного языка: *«проиграл больше всех финалов»* / *«чаще других становился вице-чемпионом»* (*ha perdido más finales / ha sido más veces subcampeón*).
* **Ясность условий и ограничений:**
  * Если вопрос касается выборки, обязательно указывать: *«Из перечисленных...»* / *«De estos clubes...»* / *«Welcher dieser Vereine...»* / *«Tra questi club...»* / *«Նշվածներից...»*.
  * Если вопрос касается конкретного регламента или сезона, этот регламент должен быть указан (например, *(38 игр)*).

---

## Чеклист перед фиксацией любого Batch-файла

1. [ ] **Актуальность:** Проверены рекорды и титулы на дату аудита (нет устаревших фактов).
2. [ ] **Терминология:** Нет калек типа «Golden Hat Trick» или «Golden Double»; термины естественны для ES, DE, IT.
3. [ ] **Факты:** Ровно один верный ответ, нет пересечений и дублирования правильных вариантов.
4. [ ] **Переводы:** Поля `right_answer` совпадают с текстом вариантов, буквы A/B/C/D синхронизированы по всем языкам, пройдена валидация скриптом.
5. [ ] **Смысл:** Вопрос звучит естественно, грамотно и понятно футбольному фанату.
